Instructions

In this study, you will view 50 different line charts, each accompanied by one question designed to identify the patterns you see.


For each visualization, you will be asked: "What pattern do you see in the line chart?"

There are 7 choices, each representing a line chart pattern. If the pattern does not align with the 7 given patterns, please select "Other" and type in your answer.




You will have 15 seconds for each question. There is a static screen for half a second between each question to clear the previous visual stimuli. Please answer as accurately and honestly as possible to help us better understand how people identify line chart patterns in real-world contexts.


When you're ready to begin, click "Start Study" below. The study should take approximately 20-30 minutes to complete.
